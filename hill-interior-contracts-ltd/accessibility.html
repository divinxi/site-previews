Accessibility

Hill Interior recognises the importance of providing a website that is accessible to all user groups, including the disabled.

Please let us know if you have any questions or feedback regarding the accessibility of this site, or if you experience any difficulty using it: call 0121 421 3377 or email info@hillinterior.co.uk.

Accessibility features

We have implemented the following features to make this website easier to use, including for screen reader users, keyboard users and users of text-only browsers.

Headings and navigation menus

  • HTML heading tags are used to convey document structure. H1 tags are used for main titles, H2 tags for subtitles, and so on.
  • Navigation menus are marked up as HTML lists, so the number of links is read out at the start and the list can be skipped easily.
  • A "Skip to content" link is provided at the top of each page for keyboard users.

Images

All images used in this site include descriptive alt attributes.

Text size

You may change the text size of this site to your preference using your browser's zoom or text size settings.

Style sheets

This site uses cascading style sheets for visual layout. If your browser or browsing device does not support stylesheets at all, the use of structured semantic markup ensures that the content of each page is still readable and clearly structured.

JavaScript

The use of JavaScript has been kept to an absolute minimum. Where it is used, all pages remain usable should JavaScript be turned off.

Links

Link text has been written to make sense out of context.
